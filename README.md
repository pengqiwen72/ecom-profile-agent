# 电商买家画像智能体（云集优选）

基于 **LangGraph** 的电商买家画像系统：坐席在侧边栏一键生成 **32 项电商画像**（消费偏好 / 价格敏感度 / 流失风险等）→ 人工确认 → 写入后台会员详情落库；并内置会员标签、导购话术、售后客服、日程安排等子图链路。

> 本项目是「基于工作中同类系统架构，抽取出的个人可运行 demo」，不是生产代码；演示数据全部虚构。

## 功能特性

- **一键画像生成**：LangGraph 多子图编排，产出 32 项画像维度，坐席可逐项修改后确认
- **人工确认闸门**：所有写入后台的动作必须经过人工确认，落库操作幂等
- **会员标签 / 导购话术 / 售后客服 / 日程安排**：四个独立子图，可单独触发
- **坐席侧边栏**：嵌入式 Web 侧边栏，登录后即可在会话中触发画像/标签/话术生成
- **后台管理**：会员列表、会员详情、画像与标签落库展示

## 技术栈

Python · LangGraph · FastAPI · Playwright

## 项目结构

```
ecom_agent/     LangGraph 智能体服务（:2024，langgraph dev）
ecom_admin/     后台管理（:5000，会员详情落库展示）
ecom_sidebar/   坐席侧边栏（:8000，触发画像/标签/话术生成）
ecom_client/    客户端辅助模块
start_all.bat   Windows 一键启动脚本（智能体 → 后台 → 侧边栏）
```

## 快速开始

```bash
# 1. 各模块配置 .env（大模型 API Key、坐席与后台账号；.env 不入库，见各目录 .env.example）
# 2. 启动智能体（先起，其余服务依赖它获取 token）
cd ecom_agent && langgraph dev --port 2024 --no-browser --no-reload
# 3. Windows 下可直接双击根目录 start_all.bat 一键启动全部服务
# 4. 侧边栏 http://127.0.0.1:8000/ecom_web/login.html 登录后触发画像/标签/话术生成
```

## 说明

- 各子服务端口：智能体 `2024` / 后台管理 `5000` / 侧边栏 `8000`
- 画像落库依赖后台会员详情接口，人工确认前不会产生任何写入
- 详细架构与链路说明见各目录内文档
